- `git diff --check`: passed.
- Generated PDF samples, an eight-page stress export, and the five DOCX packages were inspected as described above. The unit suite writes reproducible export samples under `/tmp/campus-cv-qa`.

For a custom Chromium installation, set `CAMPUSOS_CHROMIUM_PATH`. The Playwright config starts the development server automatically. For restricted CI, `CAMPUSOS_PYODIDE_DIR` can point to the **exact Pyodide 0.27.7 npm package**: the browser test serves those original runtime files in place of the CDN downloads. This runs actual Python/WASM, not simulated Python output.

## Scope and external dependencies

- Opportunity HTTP/DNS and Gemini cases use controlled response fixtures. No production Gemini key was supplied, so paid/live Gemini requests and arbitrary external recruitment sites were not certified. JavaScript-only pages, blocked sites and pages without adequate evidence are excluded rather than falsely verified. Search may legitimately return no results.
- The 41 new lessons are original CampusOS material covering the requested topics, not a wholesale copy of W3Schools. MySQL requires a real server; numerical/plotting examples require their runtime packages. Python's initial runtime and optional packages require network access in normal deployment.
- IndexedDB remains browser/origin-local storage, consistent with the existing local-first architecture; it is not cross-device cloud file storage.
- Preview, PDF and Word share facts and styling; pagination can vary with each renderer. DOCX package/XML integrity was checked, but Microsoft Word/LibreOffice visual rendering was not available here. The small built-in PDF exporter retains its existing WinAnsi font coverage; browser Print or DOCX preserves broader Unicode scripts.
